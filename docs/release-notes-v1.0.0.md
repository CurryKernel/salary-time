# 工资实时统计 v1.0.0

一款常驻桌面的工资悬浮窗：实时显示**今天、此刻已经挣了多少钱**，并统计本月、本周累计收入。支持 21.75 天标准计薪与「当月实际工作日」两种口径，月末周六按双倍基础工资计算。

## 下载

| 平台 | 文件 | 大小 | 说明 |
| --- | --- | --- | --- |
| Windows 10 / 11（x64） | `SalaryTime-Setup-1.0.0.exe` | 约 116 MB | 安装版，可选安装目录，自动创建桌面快捷方式 |

macOS 用户请按 [macOS 安装教程](macos-install.md) 拉取源码后执行 `npm run install:mac`，会安装一个可双击的「工资实时统计.app」，无需 Apple 开发者账号或代码签名。

## 功能亮点

- **实时收入**：今日已赚金额每 100ms 刷新，按工时进度精确到分；午休冻结，下班满额。
- **本月 / 本周累计**：显示已累计金额、整月 / 整周预计收入和进度条。
- **两种计薪口径**
  - 默认按 21.75 天摊算；
  - 勾选「按当月实际工作日计算」后，按当月周一至周五天数摊算，适合查看当月已挣多少。
- **月末周六双倍**：当月最后一个周六按 `基础工资 ÷ 计薪天数 × 2` 计算，不含绩效。
- **可自定义**：基础工资（默认 20000）、绩效工资（默认 5000）、计薪天数（默认 21.75）、上下班与午休时间。
- **桌面体验**：无边框圆角悬浮窗、拖动移动、置顶、隐藏到托盘、一键退出、开机自启动、设置自动保存。

## 使用说明

| 操作 | 说明 |
| --- | --- |
| 拖动标题栏 | 移动悬浮窗，位置自动记住 |
| 图钉按钮 | 切换窗口置顶 |
| 齿轮按钮 | 打开 / 关闭设置，修改后自动保存 |
| 减号按钮 | 隐藏到系统托盘，单击托盘 ¥ 图标恢复 |
| × 按钮 | 退出应用 |
| `Esc` | 从设置返回主界面 |

遇到法定节假日或调休时，勾选「按当月实际工作日计算」后，在「当月工作日」里手动填写实际计薪天数即可。

## 注意事项

- Windows 安装包未做商业代码签名，首次运行若提示「Windows 已保护你的电脑」，请点击「更多信息 → 仍要运行」。
- 「月末周六」指每月最后一个周六，属于额外双倍加班日，不含绩效。
- 21.75 天模式下，本月预计 = 当月工作日数 × 日薪 + 月末周六双倍，可能略高于月薪，这是按 21.75 摊算并叠加加班日的正常结果。
- 软件不内置法定节假日日历，实际工作日默认只统计周一至周五。
- macOS 推荐使用源码 + `npm run install:mac` 的方式；直接双击未签名的 DMG 在部分 macOS 上会被系统拦截。
