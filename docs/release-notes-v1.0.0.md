# 工资实时统计 v1.0.0

首个正式版本。

一个常驻桌面的工资悬浮窗：实时显示**今天、此刻已经挣了多少钱**，同时统计本月累计与本月到手。收入为「固定月薪 + 加班费」，月末周六自动转调休，周末加班可逐条选择转调休或发工资；支持五险一金、个税与党费扣除。

## 功能亮点

- **实时收入**：今日已赚金额按工时进度实时刷新，精确到分；午休冻结，下班满额。
- **本月累计 / 本月到手**：本月累计为税前收入；本月到手 = 税前 − 五险一金 − 个税 − 党费。
- **固定月薪 + 加班费**：基础工资 + 绩效工资为固定月薪，按当月周一至周五天数摊算；加班费额外计算。
- **月末周六自动转调休**：当月最后一个周六自动转 1 天调休，不计工资。
- **周末加班转调休 / 发工资**：任意周六 / 周日可添加加班记录，自定义当天加班时间，并逐条勾选「转调休」或「发工资」。
- **本月兑换配额**：可选择本月是否把调休小时数兑换为工资，支持小数小时，兑换金额按加班时薪计算。
- **五险一金**：缴费基数默认基础工资，五险默认 10.5%、公积金默认 5%，可改为固定金额或关闭。
- **个税**：手动税率（默认 10%）+ 每月减免额度，减除费用 5,000 元。
- **党费扣除**：固定金额，默认 0，在个税后扣除。
- **桌面体验**：无边框圆角悬浮窗、拖动移动、置顶、隐藏到托盘、一键退出、开机自启动、设置自动保存。

## 计算规则

```
固定月薪     = 基础工资 + 绩效工资
工作日日薪   = 固定月薪 ÷ 当月周一至周五天数
本月税前预计 = 固定月薪 + 选择「发工资」的周末加班费 + 调休兑换金额
本月到手     = 本月税前预计 − 五险一金 − 个税 − 党费
本月调休     = 月末周六 1 天 + 勾选「转调休」的周末加班天数
调休兑换金额 = 兑换小时数 × 基础工资 ÷ 21.75 × 2 ÷ 8
```

- 发工资的周末加班时薪 = `基础工资 ÷ 21.75 × 2 ÷ 8`，当天费用 = 时薪 × 实际工作小时。
- 月末周六和勾选「转调休」的加班日不计工资，只增加本月调休记录。
- 「本月兑换配额」开启后，填写的小时数按加班时薪计入本月累计、税前预计与到手，允许小数。
- 默认参数、2026 年 11 月：税前 ¥25,000.00、五险一金 ¥3,100.00、个税 ¥1,690.00、党费 ¥0、到手 **¥20,210.00**。

## 注意事项

- Windows 安装包未做商业代码签名。首次运行若提示「Windows 已保护你的电脑」，请点击「更多信息 → 仍要运行」。
- 月末周六自动转调休、不计工资；调休天数目前仅作记录，不会自动扣减已休天数。
- 党费按固定金额在个税后扣除，不参与计税。
- 个税为简化估算（手动税率 + 每月减免额度），不做累计预扣预缴、年终奖与汇算清缴。
- 五险一金仅计算个人缴纳部分。
- macOS 推荐使用源码 + `npm run install:mac` 的启动器方式；未签名的 DMG 在部分 macOS 上会被 Gatekeeper 拦截。
