# 工资实时统计 v1.0.2

一个常驻桌面的工资悬浮窗：实时显示**今天、此刻已经挣了多少钱**，同时统计本月累计与本月到手。本版包含 1.0.0 以来的全部更新，并提供 Windows 安装包、便携版和 macOS Apple Silicon DMG。

## 本版更新

- **月末周六自动转调休**：当月最后一个周六自动转 1 天调休，不计工资。
- **周末加班转调休 / 发工资**：任意周末加班可逐条勾选「转调休」或「发工资」；转调休不计薪，只累计调休天数。
- **党费扣除**：五险一金区域新增党费，默认 0，在个税后扣除。
- **本月兑换配额**：可选择是否把调休小时数兑换成工资，支持小数小时，兑换金额按加班时薪计算。
- **工资单页**：按月份查看固定月薪、加班费、调休、五险一金、个税、党费与到手金额。
- **关闭到后台**：右上角 `×` 只关闭界面，进程继续运行；托盘菜单「退出」才结束进程。再次打开启动器会恢复窗口。
- **撒钱特效**：标题栏星星按钮开关，默认关闭；整点触发，金色硬币从窗口顶部重力散落，浅色/深色主题均可见。
- **外观**：支持深色/浅色主题、自定义背景图与不透明度。
- **检查更新 / 静默更新**：设置里可手动检查；每天凌晨自动检查。开启「静默自动安装更新」后：
  - Windows 安装版下载 Setup，SHA-256 校验后 `/S` 静默安装并重启；
  - Windows 便携版替换 exe 后重启；
  - macOS 源码启动器自动 `git pull` 后重启；
  - macOS DMG 安装版暂需手动更新。

## 默认参数

| 参数 | 默认值 |
| --- | --- |
| 基础工资 | ¥20,000 / 月 |
| 绩效工资 | ¥5,000 / 月 |
| 五险（个人） | 10.5% |
| 公积金（个人） | 5% |
| 个税税率 | 10%（减除费用 ¥5,000） |
| 党费 | ¥0 / 月 |
| 加班折算 | 固定 21.75 天（仅发工资的加班） |
| 上班 / 下班 | 09:00 / 18:00 |
| 午休 | 12:00 – 13:00 |
| 周末加班休息 | 12:00 – 13:30、18:00 – 18:30 |

## 计算规则

```
固定月薪     = 基础工资 + 绩效工资
工作日日薪   = 固定月薪 ÷ 当月周一至周五天数
本月税前预计 = 固定月薪 + 选择「发工资」的周末加班费 + 调休兑换金额
本月到手     = 本月税前预计 − 五险一金 − 个税 − 党费
本月调休     = 月末周六 1 天 + 勾选「转调休」的周末加班天数
调休兑换金额 = 兑换小时数 × 基础工资 ÷ 21.75 × 2 ÷ 8
```

- 月末周六和勾选「转调休」的加班日不计工资。
- 调休天数目前仅作记录，不自动扣减已休天数。
- 工资单按本机设置与加班记录计算，暂不做月度快照。
- 个税仍是固定税率估算；2027 年起累计预扣个税、加班费次月发放等规则尚未实现。
